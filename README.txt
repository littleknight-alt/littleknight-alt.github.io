シンプルPDFノート（Googleドライブ同期版）

このフォルダの中身を「すべて」GitHubのリポジトリの一番上にアップロードしてください。
フォルダは作らず、ファイルを平らに置きます（全17ファイル）。

主なファイル
- index.html, app.css, app.js … アプリ本体
- pdf.min.mjs, pdf.worker.min.mjs, cmaps.json, fonts.json, *.wasm, *_fallback.js … PDFを表示する部品（pdf.js）
- pdf-lib.min.js … PDFを書き出す部品（pdf-lib）
- LICENSE-*.txt … 部品のライセンス

秘密の情報（パスワードや鍵）は入っていません。公開しても大丈夫です。
Googleの「クライアントID」は、アプリの画面で入力します（ファイルを書き換える必要はありません）。
